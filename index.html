Seu catálogo de ofertas, organizado do menor para o maior preço.

Esta versão funciona como catálogo local, mesmo sem GitHub. Para carregar preços reais automaticamente das lojas, é necessário conectar um servidor com acesso autorizado.

Conectar API de preços no futuro (opcional)

GitHub Pages publica a página, mas não fornece sozinho preços da Amazon ou do Mercado Livre. Para preços automáticos, conecte uma API HTTPS autorizada que permita CORS e responda a ?q=nome-do-produto com JSON neste formato:

{"results":[{"store":"Loja","title":"Produto","price":49.90,"free_shipping":true,"permalink":"https://loja.exemplo/item","thumbnail":"https://loja.exemplo/foto.jpg"}]}

Não coloque chaves, senhas ou tokens privados no HTML. O endereço precisa ser o de um servidor que já esteja funcionando.

BuscaPreço é um protótipo independente. Os preços e a informação de frete devem ser confirmados diretamente com cada loja. A primeira oferta é apenas a mais barata entre as cadastradas ou retornadas pela integração, não necessariamente a mais barata da internet. As ofertas locais ficam neste navegador e podem desaparecer se seus dados forem apagados.
